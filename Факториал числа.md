## Факториал числа

### 🤔 Что такое факториал?

**Факториал** — это произведение всех целых чисел от 1 до данного числа.

Обозначается знаком **!**.

**Например:**  
- `3!` (читается как "три факториал") = 1 × 2 × 3 = 6
- `4!` = 1 × 2 × 3 × 4 = 24
- `5!` = 1 × 2 × 3 × 4 × 5 = 120

**Главное правило:** факториал растёт очень быстро. `10!` — это уже 3 628 800.

---

### Что делает программа:
- Берёт переменную `num` и присваивает ей 1
- В цикле `for` перебирает числа от 1 до 5
- Каждый раз умножает `num` на текущее число `i`
- В конце возвращает строку `"5! = " + результат`

---

## Пример 1: факториал для числа 5

**Код:**

```java
public class Practice {
    public static void main(String[] args) {
        System.out.println(numbers());
    }

    public static String numbers() {
        int num = 1;
        for (int i = 1; i <= 5; i++) {
            num *= i;
        }
        return "5! = " + num;
    }
}
```
#### Пример вывода в консоли

5! = 120  

**Как считалось:**  
1 × 2 × 3 × 4 × 5 = 120 ✅

## Пример 2: факториал для числа 6

**Код:**

```java
public class Practice {
    public static void main(String[] args) {
        System.out.println(numbers());
    }

    public static String numbers() {
        int num = 1;
        for (int i = 1; i <= 6; i++) {
            num *= i;   // то же самое, что num = num * i
        }
        return "6! = " + num;
    }
}
```
#### Пример вывода в консоли
6! = 720  

**Как считалось:**  
1 × 2 × 3 × 4 × 5 × 6 = 720 ✅

## 💡 Пошаговое объяснение работы цикла (для 6!)
| Шаг | i | num до умножения | Что делаем | num после |
|-----|----|------------------|------------|-----------|
| 1 | 1 | 1 | 1 × 1 | 1 |
| 2 | 2 | 1 | 1 × 2 | 2 |
| 3 | 3 | 2 | 2 × 3 | 6 |
| 4 | 4 | 6 | 6 × 4 | 24 |
| 5 | 5 | 24 | 24 × 5 | 120 |
| 6 | 6 | 120 | 120 × 6 | 720 |

Вот так постепенно и получается факториал!

## Мои заметки (запомнить!)
1. `num *= i` — это сокращение для `num = num * i`  
2. Начинаю с `num = 1`, потому что если начать с `0`, всё обнулится
3. Факториал определён только для целых неотрицательных чисел
4. `0! = 1` по определению (это просто договорились математики)
5. Факториалы быстро становятся огромными: `20!` уже не влезет в обычное `int`
